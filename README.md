# 证据镜：A 股个股诊断 MVP

运行：直接打开 `dist/index.html`，或在本目录运行 `python -m http.server 8000 -d dist`。输入问题、选择公司类型、点击重新诊断。勾选“模拟数据接口失败”查看降级。

产品选择：以贵州茅台（600519）为样本。消费品经营及财务指标有公开年报原始证据。问题关键词和公司类型确定诊断维度；数值计算由 JavaScript 固定公式完成，证据卡区分正面、负面、矛盾、未知，并能打开原报告。没有接入在线模型，避免把生成文本误称为已核验事实。

数据：贵州茅台 2025 年年度报告，上交所 2026-04-17 披露。原始单位元，页面换算亿元；同比=(2025/2024-1)*100%。页面为固定快照，不宣称实时。行情、估值、同行及新闻因缺乏已验证的可调用接口而标未知。

扶摇和 iFinD：已核对扶摇公开文档，接口需 API Key；当前环境未获得授权密钥。iFinD MCP 当前未作为可调用工具暴露。没有伪造调用或保存密钥。未来应由服务端环境变量持有凭据，增加交易日、字段、单位、来源和过期时间校验；密钥不得进入浏览器或仓库。

边界：只支持一只示例股票的已核验年报快照；公司类型切换展示维度选择机制，不把茅台数据冒充银行或科技公司数据。无在线 LLM、实时行情、同业排名或交易建议。
